# Gennetex ERP — Windows

- `Gennetex-ERP-1.0.6-Windows-x64-Setup.exe` — standard Windows 10/11 installer
- `Gennetex-ERP-1.0.6-Windows-x64.msi` — managed/enterprise installer
- `Gennetex-ERP-1.0.6-Windows-x64-Portable.exe` — direct portable executable

All three builds connect to the same Firebase ERP project as mobile and web.

Current release: `1.0.6` (Verify.mn onboarding, corrected Tauri API CSP/CORS, private revenue dashboard). Previous installers are retained for rollback.
