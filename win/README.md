# Gennetex ERP — Windows

- `Gennetex-ERP-1.0.7-Windows-x64-Setup.exe` — standard Windows 10/11 installer
- `Gennetex-ERP-1.0.7-Windows-x64.msi` — managed/enterprise installer
- `Gennetex-ERP-1.0.7-Windows-x64-Portable.exe` — direct portable executable

All three builds connect to the same Firebase ERP project as mobile and web.

Current release: `1.0.7` (native Tauri HTTP authentication, Verify.mn onboarding, private revenue dashboard). Previous installers are retained for rollback.
