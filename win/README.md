# Gennetex ERP — Windows 1.0.4

- `Gennetex-ERP-1.0.4-Windows-x64-Setup.exe` — standard Windows 10/11 installer
- `Gennetex-ERP-1.0.4-Windows-x64.msi` — managed/enterprise installer
- `Gennetex-ERP-1.0.4-Windows-x64-Portable.exe` — direct portable executable

All three builds connect to the same Firebase ERP project as mobile and web.
