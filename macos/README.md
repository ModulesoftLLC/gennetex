# Gennetex ERP — macOS

- `Gennetex-ERP-1.0.4-macOS-Apple-Silicon.dmg` — M1/M2/M3/M4 and newer Apple Silicon Macs
- `Gennetex-ERP-1.0.4-macOS-Intel.dmg` — Intel x64 Macs

Both native builds connect to the same Firebase ERP project as mobile and web.

Current release: `1.0.5`. Previous `1.0.4` files are retained for rollback.
